# Бесконечная лента новостей 📰

Одностраничный новостной сайт с бесконечной прокруткой, реализованный на чистом JavaScript + SQLite.

> ⚠️ Учебный проект 2022 года. Код содержит исторические артефакты и неоптимальные решения.

## 🚀 Стек технологий

- **Frontend:** Vanilla JavaScript, HTML5, CSS3
- **База данных:** SQLite (через sql.js в браузере)
- **Backend (опционально):** PHP + SQLite
- **Библиотеки:** jQuery (для AJAX), sql.js

## ✨ Основные возможности

### Бесконечная прокрутка
- Автоматическая подгрузка постов при скролле
- Throttling для оптимизации производительности
- Определение окончания контента
- Пагинация по 5 постов

### Два режима работы

**1. Клиентский (sql.js)**
- SQLite база загружается в браузер
- SQL-запросы выполняются на клиенте
- Данные кэшируются в localStorage
- Не требует сервера

**2. Серверный (AJAX + PHP)**
- Классический клиент-сервер
- PHP обрабатывает запросы к SQLite
- Возвращает готовый HTML
- Требует веб-сервер с PHP

### Адаптивный дизайн
- Бургер-меню для мобильных устройств
- Анимация открытия/закрытия меню
- Responsive layout

## 🗄️ База данных

Структура таблицы `news`:
- `ID` — ID новости (PRIMARY KEY)
- `titles` — заголовок
- `bodys` — текст новости
- `img_url` — URL изображения
- `urls` — ссылка на полную версию
- `date` — дата публикации

## 🐛 Известные проблемы
SQL-инъекции в PHP-обработчике (используется конкатенация строк вместо prepared statements)
Дублирование кода между клиентской и серверной версией
Нет обработки ошибок сети
Жёстко прописанные пути к файлам

## 📝 Примечания
Проект был создан в 2022 году в процессе самообучения. Основная цель — реализовать бесконечную ленту новостей двумя разными способами: полностью на клиенте (sql.js) и классическим клиент-серверным подходом (AJAX + PHP).
Код содержит "исторические артефакты" — неоптимальные решения и закомментированный код, которые остались как часть процесса обучения.
